## 1. Overview

- **Project Description:** Single-page production portfolio showcasing applied AI engineering, multi-agent architectures (LangGraph), biometric computer vision (ArcFace/RetinaFace), enterprise SAP automation, and high-throughput RAG systems. Built with rich cyber-luxe aesthetics inspired by the `mubx.dev` standard.
- **Tech Stack & Versions:**
  - **Bundler & Build Tool:** Vite `^8.3.0` (ES modules, zero React/Next.js runtime overhead)
  - **3D Graphics Engine:** Three.js `^0.186.0` (Interactive WebGL Neural Core)
  - **Motion & Scroll Architecture:** GSAP `^3.15.0` (with ScrollTrigger), Lenis `^1.3.26` (smooth inertia scrolling)
  - **Styling:** Custom Vanilla CSS Design System (`src/styles/main.css`, ~2,424 lines, dark obsidian/cyan/gold palette)
  - **Backend / Serverless:** Node.js API endpoint (`api/contact.js`) integrating with Supabase PostgreSQL (`contact_submissions` table) and Resend Email API
  - **Typography:** Google Fonts CDN (`Inter`, `JetBrains Mono`, `Sora`)
- **Execution Commands:**
  - `npm install` — Installs project dependencies (`three`, `gsap`, `lenis`, `vite`)
  - `npm run dev` — Starts local Vite development server on port 3000 (with built-in `/api/contact` middleware)
  - `npm run build` — Compiles production bundle into `dist/`
  - `npm run preview` — Serves local production build from `dist/`
